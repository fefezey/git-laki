# Git Laki

Kolu çek, çark bugün GitHub için ne yapacağını seçsin: bir açık kaynak projeye katkı, sıfırdan küçük bir proje ya da bir profil işi.

Çarktaki her maddenin ne olduğu ve çıkınca ne yapılacağı [REHBER.md](REHBER.md) dosyasında.

## Kullanım

`cark.html` dosyasını tarayıcıda aç.

- **Boşluk** ya da kola tıkla: çevir
- **T**: renk temasını değiştir
- **H**: çekim modu (yardımcı yazıları gizler)
- **⚙**: listeyi düzenle (`sahip/depo` biçiminde yazılan maddeler için GitHub linki çıkar)
